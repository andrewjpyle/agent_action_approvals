A durable approval queue for agent-initiated actions. The agent enqueues a row, a human decides it, and a worker runs it only if approved, and at most once.

A row, not a paused process
Pending actions survive restarts and redeploys, and stay queryable.
02
Every transition is a compare-and-swap
Two deciders or two workers on one row: exactly one wins.
03
Auto-approval ships dark
Default deny, fail closed, behind a kill switch that starts off.
